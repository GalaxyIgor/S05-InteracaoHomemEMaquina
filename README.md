# README para Projeto WebApp – Faculdade

Este README foi estruturado para facilitar a documentação e compreensão do projeto de webapp universitário, baseado na organização de pastas presente na imagem fornecida.
Projeto WebApp – Faculdade

Este repositório contém o desenvolvimento de um webapp voltado para atividades acadêmicas, criado como parte de um projeto da faculdade. O projeto visa aplicar conceitos fundamentais de desenvolvimento front-end moderno, incluindo responsividade, componentes reutilizáveis e integração de mídias.
Estrutura de Pastas

    01 - Armario
    Funcionalidades relacionadas ao armazenamento ou gerenciamento de conteúdo.

    02 - Grid e Responsividade
    Implementação de layouts utilizando grid e técnicas de design responsivo para garantir boa visualização em diferentes dispositivos.

    03 - Cores, Tipografia e Ícones
    Definição da identidade visual do app: paleta de cores, estilos tipográficos e ícones personalizados.

    04 - Imagens e Vídeos
    Gerenciamento e exibição de mídias: imagens de apoio, vídeos explicativos ou institucionais.

    05 - Interação e Animação
    Elementos que trazem dinamismo para o app, tornando a interface mais intuitiva e atrativa.

    06 - Componentes e formulários
    Componentização de elementos da interface e formulários para coleta de informações dos usuários.

    07 - Versao com Função News
    Implementação de uma feature para notícias acadêmicas dentro do app.

    08 - Versão Separada/Inatel App
    Variante do projeto focada em funcionalidades específicas do contexto Inatel.

    09 - Refatorando/Inatel App
    Refatoração de código visando melhorias técnicas e de organização, especialmente para o app do Inatel.

#Tecnologias Utilizadas

    HTML5, CSS3 (com suporte a Grid e Flexbox)

    JavaScript ES6+

    Bibliotecas de animação (ex: Animate.css, GSAP)

    Frameworks/bibliotecas de componentes

    Ferramentas para responsividade (media queries)
